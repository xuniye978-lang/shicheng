# 拾程 · 秋招工作台

面向秋招与实习的个人求职工作台，支持岗位筛选、条件匹配、流程追踪、JD 快照、笔面试复盘及改进行动。

这是作品展示版。默认岗位、流程和复盘均为虚构示例，不代表企业正在招聘。页面无需登录；用户操作仅保存在访问者自己的浏览器中，项目不包含个人求职记录、账号或密钥。公开展示未连接自动招聘采集服务。

## 部署到 GitHub Pages

将本目录的 index.html、README.md 和 .nojekyll 上传到公开仓库根目录。在 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 /(root)，保存后等待部署成功。以 Pages 页面实际生成的 HTTPS 网址为准。

## 体验

打开网页即可使用。求职总览默认包含虚构示例；求职偏好预设深圳、广州及产品、数据、运营等方向，可随时修改。数据保存在当前浏览器，清理网站数据会清除本地修改，也可通过页面导出 JSON 备份。

## 实现

HTML / CSS / JavaScript，无运行时第三方依赖，适合静态托管。采用明确规则进行条件匹配和复盘提示，没有接入大模型推理。项目借助 AI 编程工具进行辅助实现与验证。
